## Monorepo Structure

Softmaple is organized as a Turborepo monorepo with the following structure:

```
softmaple/
├── apps/
│   └── web/           # Next.js 16 application
├── packages/
│   ├── db/            # Prisma database client
│   ├── ui/            # Shared UI components
│   ├── editor/        # Lexical editor extensions
│   ├── md2latex/      # Markdown to LaTeX converter
│   ├── eslint-config/ # Shared ESLint configuration
│   ├── typescript-config/ # Shared TypeScript configuration
│   └── config/        # Shared configuration utilities
├── docs/              # Documentation (this site)
├── turbo.json         # Turborepo configuration
└── package.json       # Root workspace configuration
```

## Getting Started

### 1. Clone and Install

```bash
# Clone the repository
git clone https://github.com/softmaple/softmaple.git
cd softmaple

# Install dependencies
pnpm install
```

### 2. Environment Configuration

Create your `.env` file from the example:

```bash
cp apps/web/.env.example apps/web/.env
```

Required environment variables:

```env
# Database URLs
DATABASE_URL="postgresql://user:password@localhost:5432/softmaple"
DIRECT_URL="postgresql://user:password@localhost:5432/softmaple"

# Supabase Authentication
NEXT_PUBLIC_SUPABASE_URL="your-supabase-project-url"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your-supabase-anon-key"

# Collab WebSocket service (EG-walker persistence)
NEXT_PUBLIC_COLLAB_WS_URL="ws://localhost:4001/ws/document"
```

### 3. Database Setup

Initialize the database with Prisma:

```bash
# Generate Prisma client
pnpm --filter @softmaple/db db:generate

# Run migrations
pnpm --filter @softmaple/db db:migrate

# (Optional) Seed the database
pnpm --filter @softmaple/db db:seed
```

## Development Commands

All commands should be run from the repository root:

### Core Commands

```bash
# Start development server (all apps)
pnpm dev

# Build all packages and apps
pnpm build

# Run linting
pnpm lint

# Format code with Biome
pnpm format
```

### Package-Specific Commands

Use the `--filter` flag to run commands for specific packages:

<CodeGroup>

```bash Web App
# Type checking
pnpm --filter @softmaple/web typecheck

# Run E2E tests
pnpm --filter @softmaple/web test:e2e

# Build production
pnpm --filter @softmaple/web build
```

```bash Database
# Generate Prisma client
pnpm --filter @softmaple/db db:generate

# Run migrations
pnpm --filter @softmaple/db db:migrate

# Open Prisma Studio
pnpm --filter @softmaple/db db:studio
```

```bash Tests
# Run md2latex tests
pnpm --filter @softmaple/md2latex test

# Run with coverage
pnpm --filter @softmaple/md2latex test:coverage
```

</CodeGroup>

## Git Workflow

### Branch Naming

Create branches with timestamp suffix:

```bash
git checkout -b feature/my-feature-$(date +%s)
```

### Commit Convention

Use conventional commits:

```
type(scope): summary

Types: fix, feat, build, chore, ci, docs, style, refactor, perf, test
Scope: apps/web, packages/<name>, or empty for root changes
```

Examples:
- `feat(apps/web): add document sharing`
- `fix(packages/db): resolve migration issue`
- `chore: update dependencies`

## Testing

### Unit Tests

Unit tests use Vitest and are located in `packages/md2latex/tests/`:

```bash
pnpm --filter @softmaple/md2latex test
```

### E2E Tests

End-to-end tests use Playwright and test the full application:

```bash
# Run E2E tests
NEXT_PUBLIC_E2E_TEST_MODE=true pnpm --filter @softmaple/web test:e2e

# Run smoke tests only
pnpm --filter @softmaple/web test:e2e:smoke
```

## Troubleshooting

Common issues and solutions:

<AccordionGroup>
  <Accordion title="pnpm: command not found">
    Install pnpm globally:
    
    ```bash
    npm install -g pnpm
    ```
  </Accordion>
  <Accordion title="Database connection failed">
    Ensure PostgreSQL is running and the DATABASE_URL is correct:
    
    ```bash
    # Check PostgreSQL status
    psql -U postgres -c "\l"
    ```
  </Accordion>
  <Accordion title="Husky hooks failing">
    If pre-commit hooks fail, you can bypass them temporarily:
    
    ```bash
    HUSKY=0 git commit -m "your message"
    ```
    
    But make sure to fix any issues before pushing.
  </Accordion>
  <Accordion title="Module not found errors">
    Regenerate Prisma client after schema changes:
    
    ```bash
    pnpm --filter @softmaple/db db:generate
    ```
  </Accordion>
</AccordionGroup>
