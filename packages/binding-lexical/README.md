# `@softmaple/binding-lexical`

Thin Lexical binding for `@softmaple/block-model`. Surfaces import this
package instead of talking to EG-walker or the block model directly.

```bash
pnpm --filter @softmaple/binding-lexical test
pnpm --filter @softmaple/binding-lexical typecheck
pnpm --filter @softmaple/binding-lexical build
```

Layering: [`docs/design/surface-bindings.md`](../../docs/design/surface-bindings.md).
