# `@softmaple/collab-protocol`

Authenticated EG-walker collaboration wire protocol (document and presence
messages, credentials, and validation). Hosts and clients share this package;
room semantics live in `@softmaple/collab-runtime`.

```bash
pnpm --filter @softmaple/collab-protocol test
pnpm --filter @softmaple/collab-protocol typecheck
pnpm --filter @softmaple/collab-protocol build
```
