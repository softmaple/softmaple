## Prerequisites

Before you begin, make sure you have the following installed:

- Node.js 20+ (LTS recommended)
- pnpm 9.0+
- PostgreSQL (for database)
- Git

## Setup Instructions

<AccordionGroup>
  <Accordion icon="github" title="1. Clone the repository">
    Clone the Softmaple repository from GitHub:

    ```bash
    git clone https://github.com/softmaple/softmaple.git
    cd softmaple
    ```
  </Accordion>
  <Accordion icon="package" title="2. Install dependencies">
    Install all dependencies using pnpm:

    ```bash
    pnpm install
    ```

    This will install dependencies for all workspaces in the monorepo.
  </Accordion>
  <Accordion icon="gear" title="3. Set up environment variables">
    Copy the web and database environment files and configure them:

    ```bash
    cp apps/web/.env.example apps/web/.env
    cp packages/db/.env.example packages/db/.env
    ```

    Edit `apps/web/.env` with your configuration:

    ```env
    # Database
    DATABASE_URL="postgresql://user:password@localhost:5432/softmaple"
    DIRECT_URL="postgresql://user:password@localhost:5432/softmaple"

    # Supabase Auth
    NEXT_PUBLIC_SUPABASE_URL="your-supabase-url"
    NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY="your-publishable-key"
    NEXT_PUBLIC_COLLAB_WS_URL="ws://localhost:3002/document"
    ```

    Add the same database connection values to `packages/db/.env` so Prisma
    commands can connect when run from the database package:

    ```env
    DATABASE_URL="postgresql://user:password@localhost:5432/softmaple"
    DIRECT_URL="postgresql://user:password@localhost:5432/softmaple"
    ```
  </Accordion>
  <Accordion icon="server" title="4. Configure collaboration">
    Create `apps/collab/.env.local` from its example, then provide
    `DATABASE_URL`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, and
    `COLLAB_ALLOWED_ORIGINS`:

    ```bash
    cp apps/collab/.env.example apps/collab/.env.local
    ```
  </Accordion>
  <Accordion icon="database" title="5. Set up the database">
    Generate Prisma client and run migrations:

    ```bash
    pnpm --filter @softmaple/db db:generate
    pnpm --filter @softmaple/db db:migrate
    ```
  </Accordion>
  <Accordion icon="rocket" title="6. Start the development servers">
    Keep both commands running in separate terminals. The first starts the
    root development task without duplicating the collaboration service; the
    second starts collaboration exactly once:

    ```bash Terminal 1 — web and workspace packages
    pnpm dev --filter='!@softmaple/collab'
    ```

    ```bash Terminal 2 — collaboration service
    pnpm --filter @softmaple/collab dev
    ```

    The application will be available at [http://localhost:3000](http://localhost:3000)
  </Accordion>
</AccordionGroup>

## Development Workflow

<AccordionGroup>
  <Accordion icon="code" title="Running specific commands">
    Use pnpm filters to run commands for specific packages:

    ```bash
    # Type checking
    pnpm --filter @softmaple/web typecheck
    
    # Linting
    pnpm --filter @softmaple/web lint
    
    # Build production
    pnpm build
    ```
  </Accordion>
  <Accordion icon="test-tube" title="Running tests">
    Run tests for specific packages:

    ```bash
    # Run unit tests
    pnpm --filter @softmaple/md2latex test
    
    # Run E2E tests
    pnpm --filter @softmaple/web test:e2e
    ```
  </Accordion>
  <Accordion icon="git-branch" title="Creating branches">
    Follow the branch naming convention:

    ```bash
    git checkout -b feature/my-feature-$(date +%s)
    ```
  </Accordion>
</AccordionGroup>
