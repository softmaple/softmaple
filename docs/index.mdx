## What is Softmaple?

Softmaple is a modern collaborative document editor built with Next.js 16, featuring real-time collaboration powered by EG-walker over WebSocket with Supabase Postgres persistence, rich text editing with Lexical, and seamless Markdown to LaTeX conversion.
